# 偏差对比右栏精简

根据用户反馈，右栏保留偏差计算、法向约束、配色调整、偏差直方图与色标。移除来源说明、算法解释、逐根统计、历史批次、CSV 导出入口和结果摘要；必要的进度、耗时及异常状态仍显示。直方图设置折叠收纳，配色模式直接展开。

工程容差等数值控件改为 144px，增减按钮集中到右侧，数字使用 14px 字号。修复旧有 88px 控件及内边距挤占数字空间的问题。

## 验证

- 真实 BIM 7 / 扫描 5，在独立 Chrome 中检查 2560×1440、1920×1080、1280×720。
- 工程容差最大值 `10000.0` 可完整显示，检查后恢复原值；标签单行且无页面横向溢出。
- 手动显示范围、离散配色及色阶控件可用；法向约束支持鼠标关闭、键盘重新开启。
- 直方图有实际柱形数据，色标正常，折叠设置可展开。
- 无浏览器 pageerror；未保存显示设置或触发重新计算。
- `npm run build` 和 `git diff --check` 通过。

`panel-detail.png` 为实际右栏截图；`histogram.png` 和 `tolerance-max.png` 分别验证直方图、最大数值显示。检查指标见 `validation.json`。
