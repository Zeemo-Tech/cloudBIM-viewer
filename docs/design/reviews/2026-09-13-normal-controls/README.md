# 法向约束控件布局修复

用户截图暴露了标签被挤成竖排的问题。原有设置行使用「28px 图标 / 标签 / 控件」三列网格；新增的无图标行仍继承三列，而两列修正规则只覆盖高级设置区域。

本次将两列布局应用到所有 `.c2m-setting-row--plain`：标签使用剩余空间，控件列宽 104px，列间距 12px。标签宽度可以收缩，使用 14px 字号和 1.5 行高。

## 实际浏览器验证

使用独立的 headless Chrome / Playwright 登录本地开发站点，加载 BIM 7、扫描 5 的真实 70 根钢筋结果，进入偏差对比页。浏览器在检查结束后关闭。

- 2560×1440、1920×1080、1280×800：两行标签均为单行，宽 211px、高 21px；设置行高 46px。数值框宽 104px，开关与数值框右侧对齐，无页面横向溢出。
- 鼠标关闭约束后，半角输入隐藏；聚焦开关并按空格重新开启后，输入恢复。
- 半角输入 30 → 35 → 30 正常；未触发重新计算。
- 检查偏差显示区域，工程容差行保持正常；无浏览器 pageerror。
- `npm run build`（含 `vue-tsc --noEmit`）、`git diff --check` 和针对样式文件的 Impeccable detect 均通过。

首次交互脚本误点击 Element Plus 隐藏的 checkbox，产生自动化定位超时；改为点击可见开关容器后，上述交互检查通过。

截图与尺寸数据保存在本目录。截图已人工查看；检查范围为本次法向控件布局及相邻偏差显示区域，不代表全部功能验收。
