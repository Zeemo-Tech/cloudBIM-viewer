# 偏差计算：搜索距离与紧凑排版

2026-09-13。窄范围 Operate 模式调整，沿用现有蓝白工具面板与 14px 正文、36px 控件。用户提供的截图是视觉基线；本次不改变其他工作流步骤。

## 行为

- “最大搜索距离 mm”与“搜索半角 °”并排，法向开关与“偏差计算”标题同一行。计算与配色仍分组；压缩标题、行距、状态和分组留白，取消逐行分隔线。小于 280px 的面板内容宽度改为单列；标题/开关允许换行。
- 搜索距离范围 0.1–200 mm，默认保留此前固定的 200 mm。修改后显示“参数已修改，重新计算后生效”，不会把旧几何直接重新解释为新结果。正在计算时锁定搜索参数。
- 接口 `maxSearchDistance` 单位为米，Go 转为 Python `max_search_distance`。显式零、负数、非有限值和越界数值被拒绝；遗漏参数按 0.2 m 处理。
- 无论法向约束开启或关闭，逐筋计算均执行候选距离上限。启用法向约束时，对实际候选连线的长度检查在横向投影之前执行；反向实体边界继续生效，较小的距离设置不能被最近点回退绕过。
- 仍然只在同一钢筋实例的最近 k 个候选中筛选，不宣称扫描整个指定圆锥。
- 计算请求参数进入原有 ParamsJSON/历史批次；有效值通过 `diagnostics.rebarComparison.effective.maxSearchDistance` 返回。代理会拒绝服务忽略自定义距离的结果。旧结果缺少该字段时，前端恢复 200 mm；同时恢复已有法向开关和半角。
- 参数调整需要重新计算，配色色域与工程容差仍是独立的显示/判定参数。结果版本沿用现有产物身份机制，不改动历史版本计算规则。
