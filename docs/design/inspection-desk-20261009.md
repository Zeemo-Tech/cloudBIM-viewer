# 钢筋网片检测工作台

## 界面与集成

入口组件：`src/views/inspection/InspectionDesk.vue`。宿主通过现有 AppLayout 接入，传入 `session: AuthSession`、`projectId: number`、`projectName: string`。页面不创建服务、不控制设备、不触发偏差重新计算。

路由查询参数：

| 参数 | 含义 |
| --- | --- |
| scanId / bimId | 当前项目中的点云与设计模型，必须为正整数 |
| tab | operation 工人操作、alarms 报警展示、correction 修正操作；默认 operation |
| demo=1 | 流程演示；显示醒目标识，写入 demonstration=true |

未指定文件时，读取当前项目的文件清单，显示任务选择或空状态，不自动挂接其他项目的样本。指定文件必须同时出现在项目范围清单中，并复核资产类型与返回的项目编号。检测结果文件编号也须与所选文件一致。项目和文件切换会使旧结果请求与记录请求失效。

工人操作视图显示任务、检测数据时间、复核阈值、数据有效性、设计钢筋数、测量覆盖率和待处理问题。报警展示提供编号搜索、类型筛选、逐根定位与进入修正操作。修正操作提供确认问题、现场处理说明、申请复检、已有处理记录。

## 数据和判断边界

使用既有 `getLatestC2M`，缺少逐根数据时通过 `getC2MReport` 获取同批次归档数据；需要查找归档版本时使用 `listC2MReports`。归档版本不同于最新返回版本时标记为失效，不作为就绪结果。

只有 `fresh === true` 且存在逐根结果时才开放处理按钮。缺少 freshness 字段也不能视为有效。失效结果保留查看用途并提示进入现有分析工作区重新计算。

问题统计按互斥规则显示：无可靠测量或 missing 为“整根缺测”；review、缺少有效偏差统计或缺少阈值为“待复核”；matched 且 P95 绝对表面偏差大于当前复核阈值为“偏差超阈值”；其余为“已有测量”。“已有测量”不等于验收合格。覆盖率按 knownCount / (knownCount + unknownCount) 计算，同时显示未测设计网格采样点数量。成功对应钢筋并不消除未知采样点。

复核阈值来自结果中的 inspection.summary.toleranceM 或 visualization.toleranceLimit，明确标注“非验收阈值”；页面不设置新的验收值。时间以 Asia/Shanghai（北京时间）显示，不伪造采集时间、生产数量或设备在线状态。

定位图完全使用 longitudinalProfile 的 designCenterM、observedCenterM。采用既有 RebarDeviationDetail 的 BIM XZ 投影方向，统一等比例缩放，不插入人工网格；分离设计单元与缺测观测点时中断连线。设计灰色虚线、真实观测使用问题色、选择使用 Aether 加粗。不能将该图解读为完整网片重建或所有钢筋均已获得几何。

## 处理记录契约

GET `/alignments/bim/c2m/reports/:version/actions` 返回所有记录。界面按 resultVersion、ifcGlobalId、demonstration 分开显示真实与演示记录。

POST 同一端点，提交 `{ ifcGlobalId, action, note, demonstration }`。处理顺序为 acknowledge → record_adjustment（说明必填）→ request_recheck。只有服务器写入成功且随后 GET 成功才能推进界面状态；失败保留原步骤。不会预置演示记录，不提供手工“合格”按钮，不改变原检测状态。复检申请只保存需求，不直接启动设备或计算。

## 视觉规范和检查

延续 CloudBIM / ZEEMO 蓝白平台。主要文字 16px，操作按钮至少 42px，主要动作 54px。标题采用 Sapphire，主按钮及选择采用 Aether；辅助状态使用现有语义令牌，配合中文状态文字。表格、时间、毫米值使用等宽数字；实际表格保留内部滚动。主要目标是 27 英寸 2560×1440 输出、150% 缩放下约 1707×960 CSS 视口，同时兼容 1280×720 CSS 视口。

要求验证三种视图、无文件选择、无检测结果、fresh=false、加载失败、记录写入失败、缺测值、记录真假隔离、查询切换和键盘焦点。子任务已通过两份 Vue 文件的脚本语法与模板编译检查，并运行问题分类、缺测值保留、缺测区段与设计单元边界不连线的纯函数检查。本机副本无 node_modules，临时 npx 的 vue-tsc/TypeScript 版本组合失败，不能视为通过完整类型检查。根任务负责远程正式依赖下的 npm 构建、浏览器实测与截图验收。
