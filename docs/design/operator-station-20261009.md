# 工人操作页 · 2026-10-09

## 使用场景与界面约定

模式：Operate。扩展现有 CloudBIM 蓝白界面，不替换平台品牌或技术人员工作台。现场工人登录后直接进入 `/operator`，在 27 寸、2560×1440、150% 缩放显示器上操作；截图采用 1707×960 CSS 像素和 2560/1707 像素比，输出原生 2560×1440 PNG。手机只作基本重排检查，不是工位交付尺寸。

首页提示“构件已到位，可以开始扫描”，只保留“开始扫描”这一主要动作，准备阶段以中性灰显示设计钢筋，扫描阶段以紫色保留已扫过的钢筋表面、灰色表示未扫区域；扫描完成前隐藏偏差颜色、图例和问题统计，三步进度条只呈现状态，结果在动画完成后自动进入。结果页以三维模型为主体，右侧显示当前问题、位置核对提示和下一步操作；算法参数、配准、上传、成员管理不进入工人页。沿用平台字体和色板，正文18px、主要按钮52–78px高；选中使用青绿色立体虚线框，钢筋保持自身结果颜色；超过复核阈值的偏差分三级红色，缺测橙色、待复核紫色，其余灰色。灰色不表示通过验收。

## 权限与操作

管理员在系统管理的“成员与权限”创建现场工人账号，分配管理员本人拥有的一个项目。工人只读取所分配项目的扫描任务、当前有效结果与对应钢筋几何；无分配时显示联系管理员。后端使用数据库角色及显式接口白名单，前端隐藏菜单不能代替权限检查。管理员停用账号撤销既有会话；更换项目后旧任务不能继续访问。

处置顺序为确认问题、保存处理说明、申请复检。实际操作人 actorId 与报告所属人 ownerId 分开保存。报告版本和原始检测结论保持不可变；提交时锁定当前结果并核验版本和输入有效性，旧结果返回409。演示动作与现场动作分开，演示入口显示黄色条。申请复检不等于已补扫或已放行。

## 三维数据约定

读取当前 C2M 结果对应的真实设计钢筋三角网格 PLY。按报告 vertexStart/vertexCount 对应 IFC 钢筋，不制造钢筋形状或缺测值。保留输入 XYZ、米制单位和已有坐标；相机 Y 轴向上，不新增轴翻转、配准变换或模型缩放。只有全部顶点属于同根钢筋的三角面才映射可选；顶点数、越界、重叠、重复编号及无三角面输入均拒绝。非对称点测试验证坐标和索引映射。旋转、缩放、俯视、全图、放大所选位置均改变相机，不改模型。结果页初次进入及尚未聚焦时，切换问题只更新选中钢筋。点击“放大位置”后开启视角跟随；切换问题或点击其他钢筋时，先按钢筋轴向、上方45°对准整根钢筋；切换问题时连续转向新钢筋轴向并调整取景。手动调整的相对轴向角度、俯仰角与相对取景倍率会保留；同方向同长度钢筋保持相机距离。快速改选从当前画面继续，使用上次预定终点计算相对角度，避免多次半程转向累积。手动旋转、缩放不退出跟随；“看全图”、键盘R或“俯视”退出跟随。页面以“沿钢筋轴向跟随 · 可拖动调整角度”提示当前状态。

## 运行边界

当前没有扫描设备控制接口。准备页直接点击“开始扫描”，进入8秒激光扫描演示；完成后自动显示已有偏差结果，无需第二次点击。1/2/3步骤条使用48px数字圆标、22px步骤标题与当前步骤浅蓝底，属于进度展示，不设跳步入口。准备页的“构件已到位”是演示场景提示，真实构件就位仍需现场确认或设备接入。

扫描采用无可见发射器的竖直蓝色光幕，从上方向下投射并沿网片长边平移；不显示小圆点、扇形光束或矩形边框。落在钢筋表面的细蓝线与光幕共面，准备和扫描时不显示偏差配色。光幕后方的钢筋表面持续显示紫色，前方为灰色；覆盖边界按几何坐标截取，同一根跨区钢筋可同时显示已扫与未扫两段。网片空隙保持空白，不增加平面覆盖板或外框。图例为“已扫描（演示）／未扫描”，旁注“颜色仅表示扫描覆盖，不表示合格或偏差”。该覆盖是演示行程，不是设备回传的实际测量覆盖率。开始、完成和取消扫描均不重置相机，不为光幕扩展模型取景；准备、扫描和初次结果保持原有视角与比例。演示不改变设计坐标或生成测量值，页面持续标识演示与历史结果。该流程产生的处置若提交，自动使用独立演示记录。取消后返回准备；切换任务、刷新、模型失效和离开页面会清理动画；任务代次与结果版本共同约束完成回调。页面隐藏时暂停计时，回到页面后继续；减少动态效果模式保留进度与自动结果流程，取消空间移动光束，并以10%行程为一级更新覆盖颜色。扫描效果沿用现有绘制循环，共享钢筋几何；退出扫描释放独有材质和几何。仍需设备启动/完成/故障接口、新扫描与任务关联、重新分析及质量复核接入，才能完成现场自动检测与复检。

样本为项目2、扫描5、设计模型7，70根设计钢筋，25根超过当前10mm复核阈值、4根缺测。阈值和95%绝对表面偏差用于问题定位，不能称为已确认的移位量或合同验收结论。

## 轴向取景、虚线选择框与偏差分级 · 2026-10-09

### 当前交互

### 按分析结果说明诊断

`operator-diagnosis.ts` 只使用质量为 `supported` 的截面观测，位置描述取已测范围内偏移向量长度最大的同一个截面，横向和高度分量不从不同截面拼接。沿筋长度方向的窜动尚未测得，局部偏移不能称为整根平移。

方向固定参照工人页的“俯视”：+X向右、+Z向下、+Y抬高；旋转相机不改变文字参照。当前样本由 `rebar_bim.py` 的IFC→GLB `(x,z,-y)` 基底及实际GLB表面检查确认，钢筋2等已知非对称点和顶视投影单测进一步核验。位置向量为 `observedCenterM - designCenterM`，米转毫米后显示。未重复应用旧配准工作台 engineeringRoot 的显示旋转。未来其他导出器若使用identity基底，须重新核对模型与工人页Y-up显示约定，不能把当前样本坐标当作API通用承诺。

- 位置示例：钢筋3已测最大偏移处为“俯视向下26.4mm；降低0.5mm”。钢筋14为“俯视向右14.1mm；抬高0.5mm”。数值是相对设计的实际偏向，不是指示工人向该方向调整。
- 直径取可靠截面中绝对半径差最大的截面，使用该处带符号半径差的2倍，展示局部拟合直径、对应设计直径及偏粗/偏细。报告没有独立直径限值，不套用表面10mm复核阈值。肋纹和噪声仍可能影响局部拟合值，界面保留“约”，限值配置留在分析资料中。
- 弯曲仅用 `bending.quality=supported` 且有效的 `residualBowM`，这是扣除整体平移与线性倾斜后的偏离。`maxCentrelineDepartureM`包含整体偏移，不能当成过弯证据。钢筋2有4.6mm弯曲偏离；钢筋3没有连续覆盖支撑，显示“待补扫”。报告未设置弯曲限值，不能自动宣布超差。
- 缺测显示“缺测，需补扫”，提示现场核对在位情况、排除遮挡和漏扫后补扫。没有有效测量时，不生成移位、直径或弯曲结论。归属或统计待复核时同样保留未知。

侧栏呈现位置、直径、弯曲和可判读截面数，偏移参照可展开查看；确认调整后的编辑态隐藏诊断段落，为处理记录表单保留空间。选择框改为柔和青绿色 `#287f7c`，不与钢筋红色偏差等级或橙色缺测混用。
