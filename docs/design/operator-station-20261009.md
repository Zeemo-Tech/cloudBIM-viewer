# 工人操作页 · 2026-10-09

## 使用场景与界面约定

模式：Operate。扩展现有 CloudBIM 蓝白界面，不替换平台品牌或技术人员工作台。现场工人登录后直接进入 `/operator`，在 27 寸、2560×1440、150% 缩放显示器上操作；截图采用 1707×960 CSS 像素和 2560/1707 像素比，输出原生 2560×1440 PNG。手机只作基本重排检查，不是工位交付尺寸。

首页只有开始检测、查看上次结果两个主要动作。结果页以三维模型为主体，右侧显示当前问题、位置核对提示和下一步操作；算法参数、配准、上传、成员管理不进入工人页。沿用平台字体和色板，正文18px、主要按钮52–78px高；选中蓝、需复核红、缺测黄、其他灰，其他不表示通过验收。

视觉基线为根目录 `DESIGN.md` 中既有 CloudBIM 蓝白工作台及 ZEEMO VI 约定。工人页属于该体系的现场操作扩展，较大字号和操作区尺寸仅作用于工人页；不将这些尺寸改成全平台默认值。下列对应关系已于2026-10-09按源码核对。

布局在1400px及以上保持视口高度，结果侧栏内部滚动；1051–1399px采用350px侧栏；1050px及以下改为上下排列。交付工位采用前述1707×960 CSS视口，不能将根目录 `DESIGN.md` 中平台原有的2560×1440 CSS检查尺寸与原生截图像素混用。确认问题后，处理说明编辑态隐藏已完成的定位提示、缩短局部间距，为保存按钮保留空间。三维视图跨布局断点时按全图/所选范围重新取景并保留观察方向，普通尺寸变化保留用户视角。上述为源码行为记录；最终截图和实际操作验收以交付包运行记录为准。

既有文档及局部实现差异：

- 根目录 `DESIGN.md` 仍引用 `src/styles/variables.scss` 和 `src/styles/workspace-controls.scss`，当前文件已位于 `packages/viewer-core/src/styles/`；查找和维护应使用实际路径。
- 当前源码包不存在 `.impeccable/design.json`，根目录 `DESIGN.md` 也没有机器可读令牌前言；因此未核验侧面板令牌展示或新版文档格式一致性。此交接文档不生成第二套令牌或替换既有系统文件。
- 工人页部分浅色表面、边框、消息文字和主按钮悬停色为局部字面值。例如主按钮悬停为 `#3d53b9`，共享 `--color-primary-hover` 为 `#3e52ad`，两者并非完全相同。工人页的18px正文、52–78px主要控件亦有别于平台14px/36px默认值。这些是当前实现的局部差异，不应误报为所有样式均直接绑定共享令牌。

后续修改优先沿用共享品牌和字体令牌。若改动共享原语，除工人页外还须检查项目、CAD、设计模型、扫描点云、上传和浏览/配准返回路径；若只改工人页，检查准备、设备未接入、结果定位、确认后编辑、保存后复检和等待状态，以及1400px/1050px断点前后。状态颜色必须与文字说明并存，界面样式不能解除设备、权限或有效结果的操作条件。

## 权限与操作

管理员在系统管理的“成员与权限”创建现场工人账号，分配管理员本人拥有的一个项目。工人只读取所分配项目的扫描任务、当前有效结果与对应钢筋几何；无分配时显示联系管理员。后端使用数据库角色及显式接口白名单，前端隐藏菜单不能代替权限检查。管理员停用账号撤销既有会话；更换项目后旧任务不能继续访问。

处置顺序为确认问题、保存处理说明、申请复检。实际操作人 actorId 与报告所属人 ownerId 分开保存。报告版本和原始检测结论保持不可变；提交时锁定当前结果并核验版本和输入有效性，旧结果返回409。演示动作与现场动作分开，演示入口显示黄色条。申请复检不等于已补扫或已放行。

## 三维数据约定

读取当前 C2M 结果对应的真实设计钢筋三角网格 PLY。按报告 vertexStart/vertexCount 对应 IFC 钢筋，不制造钢筋形状或缺测值。保留输入 XYZ、米制单位和已有坐标；相机 Y 轴向上，不新增轴翻转、配准变换或模型缩放。只有全部顶点属于同根钢筋的三角面才映射可选；顶点数、越界、重叠、重复编号及无三角面输入均拒绝。非对称点测试验证坐标和索引映射。旋转、缩放、俯视、全图、放大所选位置均改变相机，不改模型。

## 运行边界

当前没有扫描设备控制接口。扫描页面明确显示设备未接入并禁用“开始扫描”；读取历史实测样本结果可用。仍需设备启动/完成/故障接口、新扫描与任务关联、重新分析及质量复核接入，才能完成现场自动检测与复检。

样本为项目2、扫描5、设计模型7，70根设计钢筋，25根超过当前10mm复核阈值、4根缺测。阈值和95%绝对表面偏差用于问题定位，不能称为已确认的移位量或合同验收结论。

前端完整构建、Go测试、Node验证以及真实账号浏览器检查见交付包运行记录。验证包括账号创建与分配、登录跳转、越权拒绝、结果与几何一致、实际WebGL旋转、逐处定位、演示隔离、过期结果禁止写入、跨管理员停用、退出内存凭据清理。截图只保存测试账号的界面，临时测试账号在验证后删除；不创建现场真实调整记录。
