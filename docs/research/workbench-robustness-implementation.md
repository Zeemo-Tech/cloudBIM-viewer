# 练武场设计证据复核

本实现仅增加练武场实验模式，生产入口仍使用原流程。`robustness_mode=off` 默认关闭；`design-evidence` 必须提供有效、绑定本次源点云的设计快照，至少运行至第 05 步。`prior_mode` 继续单独控制第 06 步。

## 数据与策略边界

设计数据统一经 `rebar_design_inputs.resolve_design_inputs` 校验，候选、匹配、验收共用同一份 aligned inventory。直径、直段端点、数量、层及邻接来自设计；水平工作台、Z 轴向上属于工程假设。候选搜索与证据阈值集中在 `RobustnessPolicy`，验收容差集中在 `AcceptancePolicy`，不逐根放宽。

第 02A/02B 和融合数组保持原样。候选在融合之后、第 05 步去噪之前形成，修改独立的复核数组；台面与硬包络始终排除。候选从固定设计半径和初始方向开始，以实测支持调整中心和轴线。内部短筋使用同层候选池，允许平面内移动。半径固定不代表直径已通过验收；验收器重新从归属点测量直径。

证据区分支持、观测反证、缺测。有效法向、圆柱/平面竞争、可见弧度和轴向占据均单独记录。支持分数仍是排序分数，未经概率校准。共享源点不能当作独立支路重复计票。暂定候选不能用于保护自身；局部重新估计法向使用邻域 PCA，不广播一个假设平面法向。局部支持重试与独立邻筋重比较有固定次数上限，没有新增支持时停止。

第 05 步可将相容残片归入已有实测圆柱；不能仅因完整候选有支持而为其小残片另造一根钢筋。第 06 步复用匈牙利匹配，比较观测候选；源点只保存一个最终 owner。已删除点不恢复，弯钩沿用原处理。局部候选替换不得引入原实例没有的几何不合格项。额外、缺失、重复和拓扑冲突保持可见。

## 验收及兼容

验收器 `design_acceptance.py` 独立读取归属点，不把设计端点或旧报告的分段端点当作观测端点。长度为观测轴向 0.1%–99.9% 分位跨度，中间遮挡不补点，未观测端部不外推。默认长度容差为 max(20 mm, 5%)，普通筋轴线位置为 10 mm、方向为 5°。短筋平面内平移豁免不影响所在层、长度、直径及方向检查。

`completed=true` 只表示计算完成。`acceptance.status` 为 `passed`、`failed` 或 `pending_performance`；缺少同条件耗时参考时不能宣布完整验收通过。逐实例几何检查与全局数量/拓扑/性能检查分开保存。

新增 `review_state:uint8`、`review_reason:uint16`、`review_changed:uint8`，NPY 行号和 LAS 的 `source_record_index` 均指向原始记录。状态码、原因码、候选来源、尝试过程、替代匹配及验收表记录在版本化 manifest / `design-evidence.json` / `design-acceptance.json` 中。原类别、instance/segment 字段及关闭模式保留。页面支持本轮改判、未通过实例、逐实例设计对照及同源同设计同线程基线切换。

## 可重复运行

使用项目 Python 3.11 虚拟环境运行隔离测试，不启动生产服务：

```bash
cd services/mesh-service
../../.cloudbim/mesh-venv/bin/python -m unittest test_design_acceptance.py test_design_candidates.py test_design_evidence.py test_design_robustness_workbench.py
```

全量基线与消融顺序运行，输出目录必须不存在，以免覆盖历史结果：

```bash
.cloudbim/mesh-venv/bin/python scripts/validate-workbench-robustness.py \
  --snapshot /absolute/path/to/validated-snapshot.json \
  --output /absolute/path/to/new-results --workers 16
```

默认依次运行关闭、新模式、关闭候选生成、关闭分类恢复、关闭拓扑重比较。后三项为离线模块消融，页面仅提供关闭/设计证据两种模式。

旧运行可独立验收：

```bash
.cloudbim/mesh-venv/bin/python scripts/evaluate-workbench-acceptance.py \
  /absolute/path/to/run /absolute/path/to/snapshot.json /absolute/path/to/new-acceptance.json
```

## 长度口径核对

冻结基线为 `b24758139f97b879fcf9a248265e0c9aed66d741`。9216369 点，16 线程，k=32。旧分段端点报告有 30 个长度超差；以实测归属点跨度计算为 22 个：17 个仍超差，13 个因口径统一不再超差，另暴露 5 个旧端点报告没有反映的超差。这是测量口径修正，不能记作识别算法的改善。

新模式是否启用须依据全量验证记录。未达到几何、拓扑或性能要求时继续默认关闭；回退直接选择 `off`，历史目录保持不变。

## 2026-09-12 全量验证结果

| 模式 | 总耗时 s | 实例 | 几何不合格实例 | 拓扑冲突关系 |
|---|---:|---:|---:|---:|
| 关闭 | 47.93 | 210 | 171 | 243 |
| 设计证据 | 63.00 | 210 | 169 | 236 |
| 关闭候选生成 | 42.16 | 210 | 171 | 243 |
| 关闭分类恢复 | 63.00 | 210 | 169 | 235 |
| 关闭拓扑重比较 | 59.89 | 210 | 169 | 236 |

以上五组均未通过完整验收。当前实现保留实验开关，默认仍为 `off`。新模式 63.00 s，相对于冻结的 40.89 s 基线约为 1.54 倍；本次关闭模式实测 47.93 s，其中持久化耗时 9.62 s，较前两次的约 2.5 s 高。所有模式均使用同机、16 线程、同源、k=32，顺序执行。

数量为 210，缺失/重复均为 0；数量正确不代表验收通过。方向超差 132→130、长度超差 22→21、位置超差仍为 33，直径超差 17→18；各项可重叠。当前主要问题仍是实测腹杆方向、长度和设计几何/连接关系的差异，不能靠修改观测轴线或延伸缺测端部消除。

关闭候选生成时，逐点类别与基线完全一致。关闭分类恢复后仍有相同的 169 个几何不合格实例；恢复模块改变了点的保留情况，但没有进一步改善当前实例验收。关闭拓扑重比较与完整新模式的几何及拓扑指标相同；本数据尚不能证明该重试带来改善。候选生成对单侧 6 mm 实例发现有明确改善，对全量场景的改善则有限。

冻结基线与新代码关闭模式的 14 组源数组完全一致；新模式的法向、工程硬边界、02A/02B 及融合证据 10 组数组也完全不变。原先几何验收通过的 39 个实例、390231 个归属源点，新增误删、错误设计归属均为 0。此结论针对这些已核实的归属点，不等于新恢复点都已有人工真值确认。新模式增加 4547 个钢筋点、减少 381 个旧钢筋点；改判区域另存多视图供审查。

完整方管表面反例经新增的实测多平面竞争检查拒绝。该检查分别在同一观测子集比较平面与圆柱误差，并去除重复平面支持。短筋的同层平移豁免贯通候选生成和全局匹配；跨越原设计位置 1 m 的测试仍能正确对应，避免匹配门槛再次锁回原位置。

108 项算法/导出 Python 测试、12 项工作台 API 测试、4 组 JavaScript 测试通过。新旧全量结果各 300000 点的真实预览文件通过实际页面加载代码的校验。6 个水平工程场景（基准、75%/50% 密度、0.25 mm 表面噪声、10 mm 遮挡、单侧表面）均得到正确的 4 个独立实例，几何验收通过；本组已标注场景钢筋精确率为 1.0。还验证了源点顺序、1/2 线程和 LAS 3/6 格式组合。全量 LAS 的 9216369 行新增复核属性、类别和 owner 与 NPY 逐行一致；硬边界钢筋点和第 05 步已删点恢复数均为 0。

当前环境没有可用浏览器提供器，未执行真实 WebGL 渲染及交互检查；不以 JavaScript 单元测试替代这一结论。
