# 02B：按底层钢筋标高直接保留水平底弦

连续水平底弦已处于底层高度范围内，但旧规则仍会用 XY 投影宽度、交点形状和夹具贴边条件将其判为夹具。按用户确认的规则，底层标高现在具有最终优先级。

## 最终行为

- 沿用原流程已经识别出的最低钢筋候选高度带，不新增切片、不细分投影、不提高栅格分辨率。
- 去除台面后，只要原始 Z 落在该底层带的闭区间内，就归为钢筋；无需再次通过细长形状、腹杆倾角或夹具边缘判定。同标高的夹具点也按这条规则归为钢筋。
- 在原有多视角腹杆、弯头恢复和夹具复核之后执行，避免后续规则把底弦覆盖回夹具。
- 高度范围外的分类、原始点顺序、坐标、法向、02A 类别和原高度层编号保持不变。
- 工作台显示“02B 底层标高保留”的范围与补回点数。删除本次尝试的细分投影计算、参数、缓存和按钮。

投影版本为 `projection-geometry-v7-bottom-height`；共享流水线版本为 `shared-segmentation-v8-component-support-bottom-height`。`bottomHeight` 报告生效范围、带内总点数、补回点数以及被该规则覆盖的夹具边缘点数。`source_bottom_height` 和 `source_bottom_height_recovered` 保存对应原始点掩码。

如果原流程没有识别出钢筋候选高度带，则不凭空创建底层范围，`bottomHeight` 为 null。

## 验证

新增回归场景包含同一底层标高的细杆、宽块和夹具边缘，检查带内全部归为钢筋、台面和带外点完全不变、层编号一致，以及不生成细分投影缓存。原几何单元测试在关闭最终标高覆盖时继续检查宽夹具和交点分类。

68 项相关 Python 测试、6 项工作台测试、Node 语义筛选及 JavaScript 语法检查通过。全量运行 `20260911T033141-74344ae2` 共 9,216,369 点，底层闭区间为 23.8818–40.8818 mm，带内 1,902,190 点全部归为钢筋；相对 v4 补回 612,687 点，其中 148,690 点原先被夹具边缘规则否决。钢筋总数由 1,659,842 变为 2,272,529。带外标签逐点一致，没有钢筋转回夹具的点。原 LAS 所有维度、行顺序、法向、02A 类别、层编号，以及 LAS/NPY/预览分类的一致性均通过核对。

02B 用时约 19.73 秒，完整运行约 41.83 秒；本轮没有生成细分投影图。
