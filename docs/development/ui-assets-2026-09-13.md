# 文件工作区统一与文件类型

> 后续调整：按用户要求，已移除三个文件页的“文件类型”筛选、表格列及 CAD 详情中的格式信息，并删除对应筛选状态和格式识别工具。保留 200px 文件名列、构件类型筛选及上传格式校验。下文截图和格式测试记录为移除前的历史证据。

导航顺序调整为“项目概述 → CAD图纸 → 设计模型”，扫描页名称改为“扫描点云”。项目入口默认进入项目概述；已有路由 URL 保持兼容。相关返回文案同步修改。

CAD 与设计模型共用同一列表实现，并分别保存筛选状态。三个文件页面均提供关键词、文件类型、构件类型、状态和日期筛选，以及重置、刷新、独立上传和分页。CAD 不再只展示 ready 文件卡片，处理中、失败等状态也可查询；新增详情与删除确认，仍使用现有资产接口。模型预览、点云分析等专业操作继续保留。空列表的“清除筛选”现在确实清空筛选，不再误开上传。

三个表格的文件名列固定为 **200px**，关闭 Element Plus 自动拉伸列宽。长文件名省略并保留完整标题提示。模型及扫描表格总列宽均为 978px，在 1280×800 的可用区域内完整展示。所有页面沿用同一套表头、行高、对齐、控件和辅助色。

## 后端文件分类核对

- `backend/main.go` 的 `Asset.Type` / `assetSummary` 返回 `bim`、`cad`、`pointcloud` 资产族，以及原始 `sourceName`，没有单独的文件格式字段。
- 同文件的上传扩展名校验及 `src/features/upload/upload.config.ts` 当前接受：设计模型 **IFC**；CAD **DWG / DXF / PDF**；点云 **LAS**。
- 新增的“文件类型”列和筛选依据原始文件名扩展名识别，不依赖数据库迁移。没有扩展名的记录标为“未知”；格式大小写归一。不会将 RVT 等未支持格式标成可上传类型。
- CAD 的“查看详情”展示原有归档数据，不声称增加 DWG/DXF 图形渲染器。
