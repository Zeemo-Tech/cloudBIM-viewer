# Scan-vs-BIM 同侧表面与实测轴线（v3）

2026-09-13。算法版本 `c2m-rebar-instance-v3`；法向约束模式的测量方法为 `observed-axis-same-side-normal-v3`。

## 对应关系与测量定义

保留去噪/拓扑阶段声明的 `designBarId`、`designUnitId` 和实例归属。不会因为扫描中心更靠近另一根设计钢筋而自动改派或排除；空间邻近不能取代拓扑身份。法向约束模式在已归属单元内部建立同侧表面对应。

设计直径 8 mm、中心 x=0，扫描整根向左平移 6 mm：设计左/右表面 x=-4/+4 mm，对应扫描左/右表面 x=-10/-2 mm。左侧输出 +6 mm、右侧 -6 mm；不得将设计左侧匹配到扫描右侧而输出 -2 mm。中心线向左偏移 6 mm，半径变化为 0。

选定对应点后，距离为 `dot(q-p, n_perp)`：`n_perp` 是投影到设计局部切向垂面的朝外网格法向。这是同侧表面的有符号法向分量，正值向外、负值向内。整体平移在圆周各位置的法向分量不同，不能用圆周有符号均值代替钢筋位移。中心线偏移向量、最大偏移和去除平移/倾斜后的残余弓高单独统计。

相比 v2，取消“候选连线必须在法向圆锥内”和“向内对应不得穿出设计实体”的限制。同侧位移允许超过直径，但完整 3-D 连线仍不能超过用户设置的最大搜索距离。关闭法向约束仍为普通实例内有符号最近点，方便比较。

## 实测截面、内外方向与缺测

1. 沿每个已对应设计单元拟合扫描截面圆心，每单元最多 16 个截面、每筋总预算 64。采样窗口半宽为 `min(15 mm, max(1 mm, length/(budget*8)))`。
2. 保留既有重定位、尺度归一化、残差剔除、最少 12 点、至少 65% 内点、160° 角覆盖、合理半径与残差检查。圆心来自圆拟合，不用可见表面点的重心。
3. 增加圆心条件性检查和宽/窄轴向采样窗口的中心稳定性检查。内窗口半宽为外窗口 1/3；有至少 12 点时要求也能拟合，中心差不能超过 `max(0.25 mm, 0.1 * fitted_radius)`。不满足时为 `unstable-section`，不输出可信中心。`centerUncertaintyM` 为条件性/残差/窗口敏感性的质量估计，不是经过标定的置信区间。
4. 仅在相邻可靠截面间插值中心和半径，不跨缺测截面。孤立可靠截面只支持原采样窗口。以扫描点减实测中心的径向向量确定宏观朝外方向，并投影到局部设计横截面；这不会把横肋的局部倾斜当成相反侧。它是轴线辅助的宏观径向，不是每个肋纹面片的重建法向。
5. 圆心/半径定义推断的局部钢筋内部；仅使用半径残差不超过 `max(1 mm, 0.25 * radius)` 的真实扫描点。拟合出的完整圆不代表完整圆周均已扫描。背面不造点，不用拟合曲面代替原始扫描对应点。
6. 在“纵向位置 + 朝外径向”坐标中建立 KD 树；限制同一设计单元、轴向窗口、法向夹角及真实搜索距离。法向点积**不取绝对值**。按这些内在坐标的距离选择对应，不按模型位置的最近欧氏点选择。
7. `knnK` 保留为首批候选数，失败且候选尚未穷尽时扩批，避免固定 k 被错误近点挤满。无可靠轴线、缺扫描侧、无对应单元、端盖或超搜索距离时输出 NaN，无最近点回退。多单元弯筋必须有明确单元归属；单单元钢筋可使用整根的已匹配实例。

这仍是设计分段引导的局部圆截面近似。严重变形、非圆截面、强肋纹与扫描噪声可能降低可靠覆盖；需结合截面数与覆盖率阅读结果。局部轴向滑移/端点长度偏差不由径向指标推断。

## UI / API / 存储

- 原法向约束开关改为“法向约束 · 同侧表面”；“搜索半角”改为“朝向容差”，范围继续为 1–90°，默认 30°。
- 保留严格双向搜索、`unknown` 回退、搜索距离和 raw float32 距离产物契约。未知值不计作零或合格。
- `measurement.longitudinalProfile` 增加 `offsetVectorM`、`radiusM`、`radiusDeltaM`、`fitRmseM`、`arcCoverageDeg`、`centerUncertaintyM`、`inlierCount` 和 `quality`。
- `measurement.crossSection` 保存最大绝对半径变化、可靠截面数和总截面数；`scanSurface` 保存方法及支持/排除点数。这些字段兼容旧报告缺省，历史 JSON 原样保留；无需新增数据库列。
- 逐筋详情和打印报告显示截面半径变化与可靠截面数。CSV 追加算法/方法和截面指标，既有列顺序保留。
- Python 服务和 Go 输入指纹都升级 v3，旧结果不会冒充新算法结果，需重新计算。历史方法说明按报告方法字段区分。
