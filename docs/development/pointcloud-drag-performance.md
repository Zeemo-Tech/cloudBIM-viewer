# 点云练武场控制网拖拽性能

2026-09-14，修复 `scripts/pointcloud-debug/viewer.js` 的控制网拟合圆管绘制。

复现结果：`20260914T120236-67f3aadd`，台面后控制网，全部设计单元，默认显示拟合层。显示 423,114 个点，210 个直段、123 个拟合弯段、23 个设计补接弯段。

原实现为中心线每一小段创建独立 CylinderGeometry、Mesh 和透明双面材质，共 6,087 个 Mesh。双面透明材质每段提交两次绘制，总计每帧 12,531 次调用。保留点云、隐藏覆盖层后仅一次调用；隐藏点云、保留覆盖层后仍有 12,530 次，确认瓶颈来自拟合覆盖层。

现在每个设计单元或弯段使用一个 InstancedMesh，保留每段原有的 12 边圆柱、直径、端点、透明度及双面绘制。按单元保留分组和元数据，筛选规则不变。显式计算实例包围盒和包围球，并在重建覆盖层时释放实例 GPU 资源。

同一 RTX 5070 Ti 浏览器、1191 × 2665 绘制缓冲区、相同结果的测量：

| 指标 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 每帧绘制调用 | 12,531 | 1,069 |
| 完整场景绘制耗时 | 约 68–72 ms | 约 3.8–4.0 ms |
| 显示点数 | 423,114 | 423,114 |
| 渲染器统计三角形数（含双面两次绘制） | 292,176 | 292,176 |

耗时为同一 `renderer.render(controlNetScene, camera)` 加 `gl.finish()` 的连续测量，排除预热；它衡量场景渲染成本，不代表所有设备的端到端拖拽帧率。
