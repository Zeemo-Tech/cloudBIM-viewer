# 03 融合后的分层设计控制网实验

入口为点云分类去噪练武场 `http://127.0.0.1:8766/`。选择控制网实验后，从同一源 LAS 依次运行法向量、台面移除、分区与分层、几何/投影分类、03 融合，再运行 03X 分层控制网。实验止于控制网，不读取旧实例编号。默认完整流程和历史结果继续保留。

控制网以本轮 `fused_class == 3` 且非台面的点为候选，采用底层、顶层、腹杆分层。实例的 `fitLayerId` 使用语义层编号 1/2/3，与设计库存中的高度层 `layerId` 不同。腹杆跨层端部需要保留邻域支持，不能按腹杆层高度硬切掉接头。

“粗对齐初始化”从保存的粗配准开始；“自动初始化”重新估计控制网初始位姿。两者上游的分层与融合都可能使用保存对齐后的设计先验，因此自动模式不是整条流程完全脱离已有配准。对称网格的位姿/身份歧义继续保留为候选轴线，不强行编号。

设计直径和长度是约束，数量不用于补造缺失观测。点云坐标、原始属性和记录顺序不变。短筋错区间、弯钩旋转、遮挡和邻筋歧义仍需单独检查。本轮尚非全部母筋节点共同参与的弹性拓扑优化。

输出：

- `control_status.npy`：0 台面，1 确认钢筋，2 待定钢筋候选，3 局部离群，4 融合排除点。状态 4 保留原点，不表示本步骤新判噪声。
- `control_instance.npy`：确认点的设计直段编号，其余为 0。物理母筋关系在报告的 `designBarId` 中。
- `control-net.json`：输入阶段、初始化、分层统计、逐段拟合状态、耗时和局限。
- `control-steel.las`、`control-pending.las`、`control-removed.las`、`control-excluded.las`：四个互斥集合，合计等于所有非台面点；保留原始属性与来源索引。
- `pointcloud-with-control-net.las`：全部源记录，保留本轮融合分类及控制网属性。预览与全量输出使用同一组来源索引。

HTTP：`POST /api/run`，`controlNetMode: "aligned" | "auto"`、`throughStep: 4`、`priorMode: "off"`。旧的 `throughStep: 2` 实验请求不再运行，已完成的早期报告仍可打开并按原阶段显示。浏览器不能提交模型路径或变换矩阵。

练武场可分别查看融合钢筋候选、确认点、待定点、离群点和融合排除点，并按底层/顶层/腹杆检查。判断漏检时应同时检查融合排除视图，区分上游漏检与控制网未确认。正式分类去噪接口及 Scan-vs-BIM 输入不会自动改用实验导出；拟合段数也不等于独立真值准确率。

## 中间漏检与邻筋混拟合修正（2026-09-14，v6）

运行 `20260914T024209-3487f12c`，同一源文件、同一融合与分层结果。中间缺失长筋为单元 #6；腹杆下方重点检查 #3/#61 和 #4/#63。v5 中 #4 与 #63 在共同长度内拟合到同一条可见圆弧；长筋多出的端部还掩盖了单向平均距离的重复判断。

本版采用以下修正：

- 每个轴向窗口保留至多 8 个不同圆心，通过连续路径选择支持点；横筋法线干扰与长筋截面的法线/圆面一致性参与筛选。

## 实现范围与判读

本轮使用“整体几何定位 → 逐直段固定半径平滑拟合 → 全量点归属与重复/歧义检查”。设计直段之间的整体相对关系用于位姿候选评价，局部允许偏移和缓慢弯曲；尚未实现所有母筋节点共同参与的弹性拓扑优化。弯钩当前不被强制拉到设计方向，也没有把钩部滚转当作已经测出的量；没有可靠直段支持的钩部点保留待定。

拟合采样与最终点归属严格分离：限制候选数仅用于求模型，模型建立后对其附近全部原始点重新判断，不把采样点数当作钢筋全量点数。局部离群点还需缺少原始邻域支撑；相邻密集表面、未建模交叉筋和旋转钩部不能仅凭圆柱残差被移除。

自动定位的一条观测线只能支持一个设计单元。若另一明显不同的位姿候选评分达到最优的 90%，则身份待定，不写确定实例编号。这个分数间隔是保守实验阈值，不是统计置信概率。仍可查看橙色虚线候选轴线（`candidateCenterlineM`），但它们不计入 `fittedUnits`，不生成已编号钢筋点，也不用于删点。

初步实测相近候选相差约一个网格间距，说明规则钢筋网仅靠整体几何可能无法唯一确定位置和身份。此时已有粗配准能提供有用的初始位置约束，但最终编号仍需检查短筋错位、邻筋竞争等情况。
