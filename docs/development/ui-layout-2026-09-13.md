# 项目资产页布局与 VI 验收（2026-09-13）

在 `dev-hong` 上完成；复用 `scripts/cloudbim-dev.sh` 管理的现有开发栈。
实际浏览使用 `http://127.0.0.1:5173` 的项目 2（YB-1 历史资产），与用户指定
10.0.0.4:5173 的工作区服务一致。原浏览器连接器被其他会话占用，因此使用独立
无头 Chrome 测试上下文，沿用仓库既有的本地测试认证方式，未修改用户浏览器。

## 交付

- 左栏顺序：设计信息（IFC、CAD、项目概览）→ 实测数据（实测点云）。移除通用
  “文件上传”导航；项目卡片默认进入 IFC 模型页。保留旧 `/upload` 深链接及上传能力。
- IFC、点云与 CAD 使用统一页标题；列表工具栏、行操作、分页和上传动作共用
  `workspace-controls.scss`。常规操作为 36px 高、8px 圆角、14px 字号。
- 筛选框使用边框而非浮雕阴影，修复旧高优先级样式覆盖共享控件的问题；表格以
  44px 表头和约 56px 数据行组织，文件名左对齐，操作列固定，分页靠近记录。
- 对比页保留原有画布排列和背景选择，控制按钮去掉发光胶囊效果；登录提交按钮
  对齐共同操作样式。保持已有配准、分析、上传、删除与就绪状态判断。
- 按 VI p.17 的明示 RGB/HEX 接入品牌色，主操作采用 `#4E66CC`；品牌锚点用
  `#102375`。未把印刷 CMYK 当屏幕色转换，也未从 PDF 重画企业 Logo。
- [VI 资料库](../design/vi/README.md)包含原件、可搜索文本、页码摘要和 JSON token；
  这是项目版本化规范资料库，没有新增业务数据库表。原件 2,370,150 bytes，摘要
  中保存 SHA-256。字体使用已安装字体优先策略，不捆绑字体文件。
- 共同规范补入 [DESIGN.md](../../DESIGN.md)，包含信息顺序、语义色、组件复用、
  字体、控件状态、表格密度、视口和截图标准。

## 浏览器验证

[最终逐页记录](../design/reviews/2026-09-13/validation-final.json)包含 27 个页面/视口/
弹窗场景，页面级横向溢出为 0，`pageerror` 为 0。真实项目有 1 个 IFC、1 个点云、
没有 CAD 图纸；未为了截图造数据。

| 检查 | 结果与证据 |
| --- | --- |
| 2560×1440 主视口、1920×1080 | IFC、点云、CAD、概览可用，无整页横向溢出；主截图保持原始 16:9 |
| Mac 1440×900、1512×982 | 筛选/操作不碰撞；点云宽表在自身区域横向滚动，固定操作列仍可操作；截图保留原生比例 |
| 页面覆盖 | 实际点击项目列表→IFC→CAD→概览→点云；分别打开 IFC、CAD、点云上传弹窗；打开项目创建弹窗并取消；访问旧上传深链接 |
| 预览和分析 | 点击 IFC 预览、点云预览、进入分析、查看实模结果；打开配准工作区和三栏结果对比 |
| 常规控件 | 实测三种上传动作和列表重置/刷新均为 36px 高、8px 圆角；主按钮白字/品牌蓝对比度 5.13:1，正文次级色/白底 7.06:1 |
| 上传状态 | 分别仅显示 IFC、CAD、LAS 类型入口；未选择文件时“开始上传”禁用；点云归档提示保留 |
| 搜索/恢复 | IFC 与点云输入无匹配关键词，出现专用无结果状态；“清除筛选”恢复实际记录 |
| 键盘 | Tab 到上传按钮有 2px 焦点；Enter 打开上传弹窗，Esc 关闭；点云测距 `aria-pressed` 从 true 经 Esc 回到 false |
| 返回 | IFC 预览返回模型列表；点云“关闭预览”回实测点云；项目卡片进入 `/design/bim` |
| 登录 | 独立未登录上下文检查登录与注册面板；没有注册或提交新账户 |

验证脚本位于忽略目录 `.cloudbim/ui-layout-20260913/`。首次自动化遇到异步加载期间
重复空状态上传按钮，以及可访问名称“全局测距”与可见短文案不一致，已校正定位和
等待条件。焦点验收采用真实 Tab 操作，未用鼠标模式的程序化 focus 代替。

## 构建、机械检查与边界

- `npm run build`（Vue 类型检查 + Vite production build）通过；仍有既有的 >500kB
  分包提示，本次没有调整构建分包。
- `git diff --check` 通过。
- Impeccable 布局预扫描无发现。最终完整扫描的 4 个 `side-tab` 命中均指向上传
  拖放区四个角标的 2px 短边，不是列表/卡片侧边强调条；为既有装饰且与此次操作
  重排无关，保留并说明。[扫描原始记录](../design/reviews/2026-09-13/detect-final.json)。
- 现有项目的 C2M 对比提示“结果已过期，请重新计算”。已验证该状态能展示；没有
  为外观验收保存配准、重算网格、运行分析、上传文件或删除资产。
- 兼容分辨率在 Chrome 中模拟，未在真实 macOS/Safari 上认证；对比度抽查不等同
  完整无障碍认证。未覆盖所有后端失败类型、海量数据或每个分析阶段的计算结果。
