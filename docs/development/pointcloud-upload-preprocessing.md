# 点云上传前处理

上传链路在原始 LAS 转换完成后，计算法向量、识别台面，再生成移除台面的 LAS 和预览瓦片；所有产物成功后上传状态才进入 `ready`。原始 `source.las` 和完整预览保留。

每次处理发布到资产目录的 `preprocess/<version>/`：

- `annotated.las`：完整源记录，增加 `normal_x/y/z`、`normal_valid`、`normal_curvature`、`normal_radius`、`shared_table_mask`。
- `cleaned.las`：只保留 `shared_table_mask == 0` 的记录，原坐标、颜色、强度以及其他源属性随记录保留。
- `manifest.json`：源内容 SHA-256、算法版本、近邻数、点数和台面模型。
- `tiles/tileset.json`：移除台面的预览，通过 `table-free` representation 暴露。

法向量存储在源扫描坐标系，近邻数固定为 32；标签用独立 Extra Bytes 属性，不覆盖原始 LAS classification。LAS VLR 记录前处理契约及来源。去噪读取这些属性并复用台面判定，仍执行与设计模型相关的钢筋/夹具分类和噪声处理。原始点云的离线算法入口仍可自行计算法向量和台面。

`GET /assets/:id/pointcloud-preprocess` 返回 `{result, version}`；历史资产未处理时 `data` 为 `null`。`POST` 同一路径为历史资产补处理，已有有效结果时直接返回。接口受资产所有权检查约束，发布与删除使用同一资产锁；处理失败不会替换已有版本。有效性校验同时比较源文件元数据与 SHA-256，能够识别保留大小和修改时间的内容替换；缓存查询因此仍有一次源文件顺序读取开销，但不会重新计算法向量或台面。

预览可在完整点云和移除台面的点云之间切换。配准、去噪和后续分析默认使用移除台面的输入；最终偏差分析仍采用设计辅助去噪后的钢筋点。没有前处理结果、文件缺失或原文件变化时要求补处理，禁止静默回退原始点云。

当前台面算法沿用现有扫描 Z 方向及近水平台面假设。未识别到台面时保留所有点；移除后不足 3 点时报告错误，避免产生空分析输入。新增处理增加一次全点法向量计算、两份 LAS 及一套预览瓦片的存储开销。

验证覆盖 LAS 记录/属性保留、持久化结果复用、禁止二次台面拟合、无台面与空结果、接口权限、失败不发布、缓存复用及输入失效。宿主 Python 测试使用 `.cloudbim/mesh-venv`，集成服务使用 `scripts/cloudbim-dev.sh` 管理。

2026-09-12 实际资产 `YB-1mesh2.0.las` 联调：9,216,369 个源点，移除 5,315,996 个台面点，保留 3,900,373 点；首次接口处理及瓦片生成约 14.65 秒。完整源属性和保留点法向量逐字段核对一致。实际保留点进入双路分类时，断言禁止调用法向量计算与台面拟合仍成功，`persistedNormalsReused=true`、`tableFitCalls=0`。未完成浏览器交互验收：当前执行环境没有可用浏览器连接。
