## 使用

搜索距离现已开放：在第三步“偏差计算”中设置“最大搜索距离 mm”，范围 0.1–200 mm，默认 200 mm。它限制实际候选连线长度，修改后需重新计算；反向搜索同时受钢筋实体边界限制。重新打开保存结果会恢复搜索距离、法向开关与半角。该参数独立于色域和工程容差，旧结果未记录时按原固定值 200 mm 恢复。界面与端到端验证见 [搜索距离与紧凑排版](../design/reviews/2026-09-13-search-distance/README.md)。

第三步默认启用「法向约束 · 垂直轴向」，搜索半角默认 30°，32 个候选；修改计算参数后需要重新计算。可关闭约束与普通实例内最近点结果比较。工程容差与显示色域仍由原控件调整。

「逐根钢筋统计」可按名称/IFC ID 选择钢筋，联动三维模型与扫描实例，查看俯视 XZ、侧视 XY 和指标、导出 CSV。「历史计算批次」查询已保存的逐筋指标/轴线剖面，不改变当前三维场景。第四步在汇总表后附投影明细，默认每页两根，可选 1/2/3 根。PDF 延续现有浏览器打印流程。

## 测量口径

设设计网格顶点为 p，对应设计拓扑直线段的单位切向量为 t，模型顶点法向为 n；将法向投影到 t 的垂面并归一化为 n⊥。对同一物理钢筋已匹配实例中的扫描候选 q，令 d=q−p。

- 双向法向圆锥筛选：`abs(dot(d,n⊥)) / norm(d) >= cos(半角)`，重合点允许通过；不只检查正半空间。
- 在至多 32 个最近邻中选择第一个通过筛选的候选。记录的距离为 `sign(dot(d,n⊥)) * norm(d−dot(d,t)*t)`（米）。它剔除轴向分量，保留相对模型法向的正负号。
- 单次查询按 8192 顶点分块，候选上限 64，并按实例实际点数缩小 k；k=1 仍执行约束。
- 覆盖距离上限 0.2 m。无候选、无设计拓扑、纵向端盖法向或无可靠实例对应时保留 float32 NaN，不回退为普通最近点。
- 局部切向来自现有实例目录中的设计直线单元；折弯使用相邻局部单元，不用整根 PCA。圆弧/钩端的精度受该目录的线段近似及覆盖范围限制。
- 缺测不算合格，也不记作零偏差。容差内比例的分母为已覆盖顶点。全部最大值只针对实际有效覆盖范围；k 有限、网格密度、扫描分布和配准误差会影响结果。

表面 `maxAbs` 为原始有限距离的最大绝对值，并保存最大值所在设计网格顶点模型坐标。它不等同于钢筋中心线最大偏移。

中心线：对每个已对应设计单元沿轴取有限截面，将扫描点投影到截面平面后作圆拟合。使用重定位、尺度归一化、残差剔除、半径合理性和至少 160° 的角覆盖检查；至少 12 个有效点、65% 保留比例。中心由圆拟合求得，不是扫描点的平均值。剖面总数每筋至多 64，缺测点保留 null，图形不跨设计单元或缺测段连线。

`maxCentrelineDepartureM` 是有效截面拟合中心与对应设计中心的最大距离；`residualBowM` 是逐直线单元拟合并扣除位移向量的常数项、线性项后最大残余长度。至少连续 5 个有效截面且覆盖该单元长度的一半才给出弓高；它是局部弯曲估计，不是完整钢筋曲率。`curvatureMInv` 当前为 null，不伪造无法支持的指标。

## 存储与 API

新增 `DBC2MReportRun` 与 `DBC2MReportBar`，通过项目已有 AutoMigrate 创建。每次计算和重着色在与当前结果替换相同的数据库事务中写入一个新快照。批次保存 owner/scan/BIM、resultVersion、输入指纹、参数、真正用于计算的配准矩阵、算法、完整诊断与秒级耗时；逐筋记录按批次、IFC ID、状态建立索引，指标存为可查询数值列，同时保留原始 JSON、剖面和最大值位置。无证据的数值为 NULL。

- `GET /alignments/bim/c2m/reports?modelScanFileId=5&modelBimFileId=7&page=1&pageSize=20` → `{items,page,pageSize,total}`。
- `GET /alignments/bim/c2m/reports/:version?page=1&pageSize=100&ifcGlobalId=...&status=matched` → `{run,bars,page,pageSize,total}`。
- 响应沿用 `{code,msg,data}`；字段为 lowerCamelCase，createdAt 为时间字符串；分页上限 200，空集返回数组。所有查询按登录用户隔离。详情的 `rawJson` 为完整逐筋记录；批次响应不重复传递全部钢筋的诊断大对象。

旧计算不虚构新增指标，也不批量回填。历史快照保留统计与剖面，**不承诺保留旧三维 PLY/逐顶点二进制产物**；这些文件仍按当前结果的原清理机制管理。删除对应资产会清理该用户相关快照。旧结果重着色时若未保存原请求矩阵，则历史矩阵留空，不用当前矩阵冒充。
