# 练武场：尺寸先验圆柱去噪

入口：点云分类去噪练武场 `http://127.0.0.1:8766` 的 **07 圆柱先验去噪**。重新运行选择计算到第 07 步（HTTP `throughStep: 8`，设计辅助启用）。按原始源点云重跑前序步骤，结果以新版本保存。

第 06 步的钢筋实例作为本步输入，已有实例编号保持不变。模型的直径用于固定半径，直段长度用于约束主轴弧长；完整物理钢筋的离散中心线提供端部弯钩与腹杆连接弯曲。模板转换为相对主直段的局部坐标，丢弃设计世界位置和方向。中心位置、方向、端部位置与弯曲绕轴转角由实例扫描点拟合。现有第 06 步的设计关联仍使用配准信息，本步没有宣称前序分类也与位置无关。

使用 Scan-vs-BIM 的 `fit_independent_axis` 拟合固定半径连续轴线。径向残差阈值为 `max(0.8 mm, 0.2 × diameter, 3 × fit RMSE)`，拟合必须有足够径向、轴向及角度证据。该阈值是保守工程参数，不是扫描仪精度标定值。

圆柱拟合和点云去噪分别记录。`fitStatus` 表示是否有可靠拟合，`status` 表示是否应用删点；点云保留不再意味着圆柱缺失。直筋以扫描轴线可见弧长中点为中心，按设计长度对称裁短或沿端部切向延长；带弯曲的实例进一步使用端部实测点，求解主轴正反向、轴向/横向微移与绕轴转角，得到连续的直段＋弯曲模型。`fittedStraightLengthM` 对应 `expectedLengthM`，含弯曲的 `fittedLengthM` 对应 `expectedShapeLengthM`；二者分别校验，不能用直段长度裁掉弯钩。`observedLengthM` 为扫描主轴可见跨度。

只有下列校验通过才应用删点：

- 拟合前的非零实例数等于设计拆分单元数，设计单元关联一一对应且没有未解析构件。
- 拟合有足够支持点，保留该实例至少 48 点且不低于输入点数的 55%。
- 扫描跨度不超过设计长度的 1.25 倍加容差；超过时仍输出设计长度圆柱，同时保留实测点以供长度复核。弯钩判断比较局部片段与按长度加权的主方向，避免把相反方向的小幅局部误差相加。没有已知形状模板的多方向实例继续保留待复核；有模板的弯钩则单独拟合端部形状。

弯钩锁定簇通过原始 `complete_cluster` 记录号保护，并从主直段轴线拟合中排除。已知弯曲的端部区域保留实测点，直段按扫描轴线残差去毛刺；有限设计端面不作为裁切扫描的平面。腹杆相邻直段各分配连接弯曲的一半，避免重复计数和漏掉弯曲。每根报告 `bendFitStatus`、实测端部支持比例和保护点数，证据有限时在界面提示复核。

数量校验只约束实例身份与数量，不证明每个点都是毛刺。局部拟合失败时保留该实例，其他可靠实例可继续去噪。整体数量/设计解析校验失败时，本步不删点。报告分别给出点云实例数、实际已拟合圆柱数、未拟合实例清单、设计长度一致性和去噪应用结果；只有实际圆柱全部拟合，`allInstancesFitted` 才为真。

查看支持整体/逐根、上一根/下一根、拟合前/保留点/移除点，以及固定设计半径的直段＋端部弯曲模型叠加。点云预览是同一组确定性抽样记录；统计和导出来自全量数据。无拟合结果的保护实例不会绘制虚构圆柱。

产物：`cylinder-denoise.json`、全量来源对齐的 `cylinder_keep.npy` / `cylinder_removed.npy`、`cylinder-steel.las`、`cylinder-removed.las`。保留点和移除点均保留原始 LAS 属性、`source_record_index` 及 `complete_instance`。原点云坐标不移动，不生成补点。此前步骤及其导出保持原义。旧历史版本缺少此步骤时仍能正常查看。

此项接入独立分类去噪练武场；主应用生产去噪接口和 Scan-vs-BIM 输入尚不自动改用本步导出。
