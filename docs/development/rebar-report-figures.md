# 第四步逐筋报告图

报告采用混合方向的 A4 页面。横向、纵向钢筋保持横版：正视图在上、俯视图在下，
右侧为设计模型定位图，下方一行显示五个局部截面。箍筋采用竖版：正视、侧视
两幅立面高度轴朝上，右上方为设计定位图，其下纵排两个弯钩法向截面，页面下方
横排三个主体截面。缺测截面保留同样大小的坐标框和缺测说明。顶部保留构件名称、层位及紧凑统计表，
测量方法的完整解释集中于摘要。绘图源为 `packages/alignment/src/rebarReportFigure.ts`，
章节及定位源为 `packages/alignment/src/rebarReportLayout.ts`。页面负责从当前结果提取几何，
生成 SVG 并供浏览器 PDF 打印使用。无需重新分类、配准或计算历史偏差。
图例、页脚及缺测说明使用“实测点云”和“拟合钢筋轴线”；数据来源与处理方法不变。

## 数据与坐标

- 蓝色实体投影来自当前 BIM 构件的真实三角网格，不对整个构件取凸包。
  从场景读取时采用 `inverse(W_bim_raw) * W_mesh` 还原 GLB 原始米制坐标，
  保留完整平移、旋转及尺度。视口的居中、工程坐标显示旋转不进入报告数据。
- 橙色离散点来自当前去噪版本的 `preview.ply`，仅保留 `label=3` 且属于
  当前钢筋 `instanceIds` 的点。`p_model = A * (p_preview + previewOrigin)`；
  `A` 优先取当前 C2M 检测快照的 `inspection.provenance.alignmentMatrix`。
  历史结果没有该字段时，仅使用已保存的完整配准矩阵。不做质心对齐或距离阈值纠偏。
- 柔性拟合使用同一结果中 `inspection.bars[].observedSegments`，其坐标已经
  是原始 BIM 坐标（米），不再应用 A。只画 `supportedIntervalsM` 内的段，
  保留不同单元、不同片段及缺测区间的断点。管面半径沿用明确标识的设计先验，
  不能据此声称测得了实物直径。
- 表中平均绝对偏差、RMSE、P95、覆盖率沿用原 C2M 数据。截面 Δ 是柔性拟合轴
  相对设计中心在该截面内的位移；不是点云质心、管面拟合残差或表面偏差，
  不直接套用表面偏差容差给出合格标识。

## 投影与抽样

所有视图使用工程坐标 `(X,Y,Z)=(GLB.x,-GLB.z,GLB.y)`，与定位图一致。
最长设计单元决定主方向：取其绝对分量最大的工程轴并固定为正向，不跟随端点顺序翻转。
设计主段在该方向较小的一端为相对坐标原点，图中用 `X′/Y′/Z′` 区别于全局绝对坐标。
主体截面垂直于该固定工程轴，箍筋两端另以钩端局部设计轴线为法向剖切；
截面内坐标均为相对于各自设计中心的位移。

| 主方向 | 正视图：横 / 纵；视向 | 第二投影：横 / 纵；视向 | 截面：横 / 纵；视向 |
| --- | --- | --- | --- |
| X | X′ / Z′；−Y → +Y | 俯视 X′ / Y′；+Z → −Z | −ΔY / ΔZ；−X → +X |
| Y | Y′ / Z′；+X → −X | 俯视 Y′ / −X′；+Z → −Z | ΔX / ΔZ；−Y → +Y |
| Z | Z′ / X′；+Y → −Y | 侧视 Z′ / Y′；−X → +X | −ΔX / ΔY；−Z → +Z |

上述工程轴截面从负方向看向正方向。视线上下方向保持不变，屏幕左右方向与原正向端视图反转，
不是只改观察方向文字。截面基 `u × v` 指向负轴侧的观察者；站号仍沿工程正轴递增，
主视图和俯视定位图不随截面视向改变。非对称点的符号和右手关系由专项测试核对。

纵向图横、纵轴分别定标，图注明示。章内共用主轴范围及两个纵轴范围，也共用 SVG 图幅尺寸，
短筋因此保持实际相对长度。范围覆盖本章全部设计网格、分类预览点及受支撑拟合管面。
箍筋竖版立面不旋转 SVG 文字，而是更换绘图基：原 `(主轴, 横轴)` 变为
`(-横轴, 主轴)`。正视为 `-X′/Z′`、视向 `+Y → -Y`；侧视为 `-Y′/Z′`、
视向 `-X → +X`，高度均向上，观察方向不变。以非对称工程点 `(2,3,5)`
核对两幅投影分别为 `(-2000,5000)`、`(-3000,5000)` mm，并验证
屏幕右向叉乘上向仍指向同一观察者。全局定位仍是真正俯视。

截面按当前构件所有五个切片的分类点、设计截交线和拟合截交线的联合范围局部放大。
同页五图共用相同毫米范围，横纵严格等比例；不同构件可使用不同放大倍数，图注明示当前毫米幅宽。
箍筋的主体和弯钩图幅尺寸不同，分别组内同尺度，不声称两组在纸上采用同一比例尺。
横纵范围均严格关于设计中心 `(0,0)` 对称，设计中心始终位于绘图区正中央，
不根据点云位置平移窗口。范围按 5 mm 向上取整，在纵向较空的一侧预留图内标注带，
同页五图标注位置一致，全部观测点及两种截交线保留在绘图区内；
不按百分位裁剪离群值，也不让本章另一根的大偏移迫使当前截面缩得过小。

横版截面在设计单元累计长度的 10%、30%、50%、70%、90% 附近选择最近的已保存采样位置，
不按偏差大小或拟合质量挑选。选定后按工程主轴正向排序；c–g 与主视图中的位置一一对应，
截面标题标出同一主轴的相对坐标，多单元时图内另标单元号。点只来自对应单元的实例，
以保存的 `windowM` 数值作为当前工程切片的半厚度，旧记录无窗口时使用 ±5 mm。
这是明确标注方向的工程切片，并非原算法的局部切线法向采样统计；不修改已有测量结果。

箍筋的 c–e 从最长主体设计单元的工程主轴 25%、50%、75% 位置选取最近的保存站位，
按主轴正向排列。f、g 分别从上下两端的设计单元中点选择站位，切片法向使用该处
局部设计切向，不能沿用固定 Z 法向；与主体平行的 180° 回钩也保留。没有对应单元或
足够站位时保留空位，不挪用主体截面。钩端切向先按主工程分量定向，再从负侧观察，
局部基 `u × v` 指向观察者；v 为投影后的模型向上，退化时用模型 Z 轴作为参照。
反转设计单元端点不翻转图像。两幅立面中 f、g 标出各自剖切平面与观察平面的交线。
所有点仍以实例所属设计单元和切片厚度筛选，拟合轴线只在保存的受支撑区间内与该平面求交。

主体截面图内标出 t、n、Δ、D₀ 和 Dₘ；弯钩截面将数值排在绘图区右侧。
两种图幅均为方形绘图区、设计零点居中且保留全部观测范围：主体零点为 `(127,126)`，
右侧弯钩零点为 `(87,85)`。测径统计仍来自全部有效测量截面，改换显示位置不改变分母或合格数。

蓝色线和橙色虚线分别为设计管面、柔性拟合管面与同一工程切面的交线，沿用设计半径。
设计段或拟合轴倾斜时均按真实圆柱截交计算椭圆，不强行画圆。与切面平行时不捏造有限闭合截交线。
没有受支撑的拟合段穿过该位置时
保留实测点，标出“该位置无可靠拟合轴线”。n 是该薄层内分类预览点数，不是
原始 LAS 的点数或拟合内点数。纵向最多显示 6000 点、每截面最多 1600 点，
固定步长抽样只影响显示，不改变表格统计或源文件。

有实测点但无拟合轴线时保留设计半径参照；没有点、受支撑轴线和有效测径证据时，
截面内容留空并标“缺测”，保留坐标框和图位，不画设计截面圆、拟合圆或零偏差。
全缺测构件仍有五个截面占位；无站位资料时注明“截面位置未提供”。主视图章内尺度
不因为当前页缺测而改变，设计模型的立面投影仍保留。

## 直径与直径偏差

`rebar_metrics.measure_bar(axis_method="sections")` 保存的是已通过质量判定的截面圆拟合半径，
其中 `radiusDeltaM = radiusM − designRadiusM`。报告只接受 `quality="supported"`、
有效观测中心、有限正半径和有限半径偏差，且排除 `radiusSource="design-prior"`。
换算为毫米：`Dₘ = 2000 × radiusM`，`ΔD = 2000 × radiusDeltaM`。

顶部逐筋表显示设计直径、测量直径均值、带正负号的直径偏差均值、最大绝对直径偏差和有效截面数 k。
均值按该构件**全部有效测量截面等权统计**，不是只统计展示的五个截面，也不是按预览点数加权。
无测径证据时保留设计直径，测量值与偏差用“—”，k 为 0；不能将缺测当作零偏差。

每张截面内标出 D₀（设计直径）和 Dₘ（该已保存站位的法向截面圆拟合直径）。
观察方向改变、工程平面斜切和图形缩放均不改变这个实体直径；椭圆长轴不是钢筋直径。
柔性拟合虚线管面的半径仍沿用设计先验，与独立圆拟合测径分开说明，不把设计先验当成实测直径。

## 章节与全局定位

按横向钢筋、纵向钢筋、箍筋排序，每章内部按层位和空间位置排序；未能判定的构件
保留在“待分组钢筋”。方向由设计主段决定，平面两组正交方向用四倍角平均建立共同基准，
反向端点不改变分组。箍筋使用设计清单的 `web` 类型或主段的竖向分量判定，
不从构件名称猜测类型。显示名称统一为“箍筋”，内部 `connector` 身份保持兼容。
摘要列出各章页码，预览按三个独立章节连续呈现。参考隧道项目
`Tunnel-Section-Analyzer/src/views/analysis/components/ReportChapterDivider.vue`
及 `TunnelReportPreview.vue` 的章节页组装，每章先显示一张独立纸张：章序、章名、
本章根数、明细页范围与六项本章统计，随后才进入逐筋明细。箍筋章节页与其明细
同为 A4 竖版，其余章节页为 A4 横版。章节页始终显示，不随章内逐筋翻页隐藏。
每章有自己的上一根/下一根与当前位置；翻动一章不会改变其他章节的选择。
报告阅读器直接移植 `TunnelReportPreview.vue` 的 `report-preview-toolbar-dock`、
`report-preview-scroll` 与 `section-page-nav` 结构和样式：缩放、编辑、全屏、导出
工具栏位于滚动容器外，滚动时始终可见；翻页条悬浮在各张纸的顶部中央，显示当前
钢筋名称与章内位置，不占用页眉排版，不再在纸外重复章节标题。章节统计保留在章节页。
箍筋竖版在低于 80% 的预览比例下同步缩小翻页条，避免遮住左右页眉。
缩放沿用隧道阅读器的纸面坐标锚点逻辑，按当前可见纸张恢复阅读位置。
翻页后键盘焦点跟随到新页面的对应按钮；首尾按钮禁用。
打印时隐藏工具栏与翻页条，完整展开各章明细并保留报告页码。
目录跳转定位到章节页。页码和目录范围包含章节页；关闭逐筋明细时一并移除章节页，
隐藏封面、摘要或启用补充附录时按实际页面重新编号。

设计清单 `inventory.bars[].points` 在后端经过 `inverse(A)` 转到了扫描原始坐标，
定位图先完整应用保存的 A 还原模型坐标；`longitudinalProfile.designCenterM` 已在模型坐标中，
不重复变换。定位俯视采用工程坐标 `(X,Y,Z)=(GLB.x,-GLB.z,GLB.y)`，从 +Z 向下看，
X 向右、Y 向上，两个平面方向严格等比例。图内显示全局设计轴线（含端部弯钩）、
同层灰色参照、紫色当前构件、比例尺及高度条。箍筋在高度条上显示跨层范围。

清单 `layerId` 是 5 mm 高程分箱，不能直接当成钢筋网层号。报告取非箍筋设计主段中点高程，
相邻高程间隙超过 `max(25 mm, 2.5 × 中位设计直径)` 时分为另一层，自下向上编号；
交叉方向钢筋的微小高差归入同一层。页面明示编号方向；这是设计几何分组，不是 IFC 楼层标识。
箍筋按其设计高程范围与各层相交关系标出“连接第 1、2 层”等；没有设计依据则显示未判定。

## 合格统计口径

摘要同时给出总量、按类型的小计、已对应/缺测/待复核、表面合格/超限、可测径、
直径合格/超限、两项均合格及有效测径截面数。合格率分母在数字旁明确列出。

- 表面偏差沿用巡检判定：`status=matched`、有覆盖顶点且 P95 绝对偏差有效，
  P95 ≤ 当前表面复核阈值为合格。该口径不表示每个顶点都在容差内。
- 直径允许偏差默认 **±2 mm**（本次用户指定），在报告配置中独立调整。
  已对应且具有有效测径截面的钢筋，以全部有效截面的最大 `|ΔD|` ≤ 阈值
  判合格；不以正负均值抵消偏差，也不只检查图中五个截面。
- 缺测、待复核、无有效数值分别保留为未评定，不纳入合格率分母。
  清空/非法直径阈值时不生成直径合格率；没有有效分母时显示缺值。
- “两项均合格”的分母为同时具备两项判定依据的钢筋，不称为整体工程验收。
  报告阈值仅用于当前报告表达，不写回分类、配准和历史 C2M 结果。

实现：`rebarReportSummary.ts`。专项测试覆盖阈值边界、无效/缺测证据、正负偏差
抵消、分类小计守恒与分母，浏览器核对真实数据与修改阈值后的统计。

## 打印与验证

首屏准备全体构件几何并计算章内统一范围，按结果版本、去噪版本、几何修订及设计布局缓存；
屏幕生成每章当前逐筋页 SVG。导出 PDF 前生成全部逐筋页，等待 SVG 挂载后再打印，
避免未翻到的页面为空。每幅图的裁剪 ID 包含构件和面板身份。图层采用 SVG，
无额外 WebGL 上下文；文字、坐标和线条随浏览器 PDF 导出。

默认内容为封面、摘要及逐筋图。旧轴线投影保留为默认关闭的“轴线测量补充附录”，
需要时可开启并选择每页 1、2、3 根，横向采用对应列数排布；附录明确标注各图独立定标。
摘要页脚保留完整结果版本号。屏幕和打印共用同一章节顺序、完整页码和图形；
打印用命名页 `rebarPortrait` 为箍筋指定 A4 竖版，其余采用 A4 横版，适应页面
兼顾横版最大宽度与竖版最大高度。只在纸张容器上固定毫米宽度，祖先容器保持自动宽度，
避免 Chromium 因横版祖先跨越竖版页而把整份报告缩至约 70.7%。实际 PDF 以
40 CSS px 页边距对应 30 pt 验证内容尺寸，而不只检查纸张方向。
