# 上传、辅助色与导航体验补充检查

在 `dev-hong` 上延续 [首页布局与 VI 落地](ui-layout-2026-09-13.md)，保留原有上传、归档匹配、配准、去噪和报告发布逻辑。根智能体负责上传、共享样式和实机检查； NAV-03 子智能体负责路由状态工具，COLOR-04 子智能体负责分析面板的颜色替换。两位子智能体均完成并停止写入，根智能体完成集成。

## 已修改

- 上传弹窗改为文件信息行、归档表单、状态/进度和提交按钮。文件名、大小、支持格式、替换和清除均可直接看到；保留拖放及原有校验。移除装饰纸张、扫描光效和大面积空白。1440×900 下弹窗由约 748px 高缩至 520px。
- 主操作使用 VI 的 Aether 蓝；普通说明使用灰蓝，完成状态使用低饱和青灰，需要注意的条件使用赭色，真正失败和删除使用低饱和玫瑰色。Element Plus 消息、标签、按钮与分析面板使用同一套变量。XYZ、钢筋类别和容差色谱保留其科学含义。
- 页面边距、主要纵向间距使用 `clamp()`；上传表单按容器宽度切换列数，弹窗内部可滚动。通过减少空白为 Mac 窗口留出空间，保留可读字体和控件尺寸。
- 预览与分析携带来源列表的 `returnTo`，关闭时返回对应来源；直接打开链接则回到模型/点云列表。只在上一条历史记录确为来源时执行 back，其余情况 replace，避免关闭后反复跳回查看器。
- 项目、IFC 和点云列表按用户、项目、页面保存筛选、页码和每页条数，刷新/返回后恢复；日期值重新解析，无效存储安全回退。
- 分析步骤保存在 URL `step` 中，等待文件与已保存结果加载后按原有条件恢复。查询参数的呈现变化不再使整个查看器重新创建。登录成功保留当前深链接。

规范已写入 [DESIGN.md](../../DESIGN.md)。VI 原文件、页码解析与标准品牌色仍在 [VI 资料库](../design/vi/README.md)，本轮辅助色明确标注为产品扩展色。
