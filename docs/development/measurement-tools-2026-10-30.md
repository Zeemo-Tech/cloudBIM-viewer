# 测量工具实施与验证（2026-10-30）

本轮落实[厂商调研清单](../research/measurement-tools-vendor-research-2026-10-30.md)前两批的取点、局部几何和测量工作流，入口覆盖 BIM 预览、点云预览、坐标配准/分析页面。原有定位、两点距离、面积工具继续可用，新增入口为 **测量 → 几何**。

## 已实现

| 功能 | 操作与结果 |
| --- | --- |
| 取点来源与吸附 | 筛选仅点云/仅 BIM；实际点云顶点、模型表面、模型三角形顶点/边中点、已有测量端点；显示候选类型。Alt 暂停辅助吸附。 |
| 放大镜 | 光标附近 3× 实时画布放大，随窗口尺寸和像素比例调整。 |
| 平面与法向 | 点云邻域稳健拟合；模型采用命中三角面的法向。显示邻域面片、支撑点、法向箭头、残差和有效点数；半径和容差可调整。 |
| 法向测距 | 先点参考面，再连续点待测点，显示垂足、垂距和沿法向正负值；支持反转法向。 |
| 两平面测量 | 两面夹角及近似平行面的法向间距。夹角超过 5°时拒绝“平面间距”，引导使用面面角或点到面。 |
| 边缘与角点 | 从局部点云提取两个/三个相交平面，求交线或交点；支持非直角相交。显示支撑面和拟合交点，缺少可靠面时拒绝结果。 |
| 局部坐标系 | 从平面或角点建立仅用于测量的右手正交坐标系。角点取首面法向为 Z，首面与第二面的交线为 X，Y = Z × X。不改变模型配准。 |
| 精确输入 | 世界/局部 XYZ 坐标、相对上一点的增量，X/Y/Z 轴约束；基础定位、测距、面积也可使用。 |
| 角度 | 三点角、四点线线较小夹角、两平面较小夹角；零长度边与退化输入拒绝求解。 |
| 圆柱 | 任意轴圆柱的半径、直径、轴线、局部支撑长度；两根圆柱无限轴线之间的最短距离。 |
| 连续操作 | 点击提交、拖动旋转/平移；撤销本次点选、重置参考、Esc 退出；正对参考面并恢复原视角。收起工具不清除记录。 |
| 保存与恢复 | 保存结果、来源资产/顶点/三角面、完整世界矩阵、拟合参数、支撑点快照和局部坐标系。三个入口均可保存并重载。清除只作用于当前坐标环境的记录。 |

基本用法：选择“仅点云”→“局部平面与法线”，移动预览后点击保存；测垂距则选“点到平面距离”，先锁参考面，再连续点击。角点可直接选择“提取角点”，或将捕捉方式改为“角点”后建立局部坐标系。圆柱需要把邻域半径调到能覆盖充分圆弧与轴向长度。

## 坐标与数据依据

- 计算统一使用米制、右手的查看器世界坐标；输入和坐标反馈明确标注 **Y 向上**。工程坐标到查看器的约定为 `(X,Y,Z) → (X,Z,-Y)`，沿用已有父变换，未修改资产、配准或源数据。
- 点云命中保存实际顶点，使用完整 `matrixWorld`，不把 `Points.raycast().point` 当作扫描点；像素容差考虑父级缩放，支持透视/正交相机、可见性和剖切。
- 拟合仅采用同类、同资产的已加载可见几何，避免把设计 BIM 混入扫描拟合。点云结果注明“点云显示采样快照”。
- 拟合样本最多 4096 点；残差和点数重新统计完整局部邻域，保存最多 256 个原坐标支撑点用于复核显示。单次邻域超过 10 万点或遍历预算超过 200 万顶点时，提示缩小范围。
- 点云调平时，点、面、法向、圆柱轴、局部坐标系和来源矩阵一起转换；保留原始局部坐标。独立预览和分析页面具有各自的原点/配准，因此以 `contextKey` 区分记录，禁止直接混用。历史无坐标环境标记的记录仍由原预览入口读取。
- 圆柱至少需要 120°圆弧、55%一致支持和足够轴向长度。支撑长度只是当前邻域覆盖长度；轴距是无限轴线最短距，不代表实体端面间净距。模型三角面法向属于模型几何依据，不是实测表面平整度。

M02 的一般曲线中心/任意线交点捕捉、M18 的独立圆拟合、M27 的已保存端点原位编辑尚未覆盖。本轮提供模型顶点/中点、拟合交线/角点、圆柱中心/轴线以及未完成点选的撤销重选。M32 当前完成的是显示采样结果冻结与来源记录；按指定原始点云分辨率回源重算仍是后续能力。第三批报表、批量导出、容差模板、体积等未纳入本轮。

## 实现与验证

公共模块位于 `packages/viewer-core/src/viewer/measurement/`：几何求解、真实顶点拾取、测量会话和持久化坐标转换分离。两个场景实现共享 `MeasurementAssistant` 和 `MeasurementAssistPanel.vue`。

验证入口：

```bash
npm run build
npm test
CLOUDBIM_MEASUREMENT_E2E=1 node scripts/test_measurement_browser.mjs
```

- 算法与会话测试：任意旋转/平移、非正交面交解、噪声/离群、稀疏/共线/近平行拒绝、大绝对坐标下毫米级圆柱、部分圆弧、完整邻域统计、输入不可变、正负垂距、面间距、三种角度、圆柱轴距、局部坐标、视角恢复和调平往返转换。
- Node 回归：36 个脚本均成功退出，平台或显式开关限定的检查按脚本条件跳过；不将跳过项当成浏览器证明。
- 浏览器：Chrome/SwiftShader、DPR 1.25，真实资产 BIM 13 / 点云 14。19 项浏览器检查通过；三个入口均验证精确坐标、90°角度、后端保存/重载和拖动不提交；实际点云点击返回真实顶点索引。
- 浏览器内临时夹具：实际界面点击验证平面、角点、圆柱；150 mm 半径圆柱得到约 149.9999999 mm，DPR 1.25 的放大镜画布为 180×180 且有完整像素；1280×800 下辅助面板完整位于视口内。该数字是已知几何夹具结果，不代表现场扫描精度。
- 浏览器测试只写入本次测量记录，并在 `finally` 删除本次记录，保留历史资产/测量/配准。本次最终浏览器检查创建并清理 11 条记录，未发生页面脚本错误或其他应用写入。原始日志与清理结果位于 `.cloudbim/measurement-20261030/`。
