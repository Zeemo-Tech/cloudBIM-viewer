# 文件列表自适应修正 · 2026-09-13

用户截图中的右侧空白来自上一轮关闭了 Element Plus 表格自动填充：各列固定宽度相加后，小于外层列表容器。此次修正 CAD 图纸、设计模型和扫描点云三个列表。

- 恢复 `fit=true`；文件名称固定 200px，元数据列使用最小宽度并分配剩余空间。
- 操作列保留固定宽度，标题和按钮组靠右排列；不覆盖其他字段。
- 保留现有筛选、分页和业务操作，不增加文件类型展示。
- 同步更新 `DESIGN.md`，避免后续再次通过关闭整表填充限制文件名宽度。

## 验证

三个页面分别检查 2560×1440、1920×1080、1512×982、1440×900、1366×768、1280×800、1152×720、1024×768，共 24 组，均通过自动几何检查。检查包括文档无横向溢出、文件名称列保持 200px、宽屏表格填满容器、操作按钮边界，以及窄屏内部滚动后操作可达。浏览器错误记录为空。

已人工查看扫描点云 2560、1280、1152 宽截图，设计模型 1920、1024 宽截图，以及 CAD 1440 宽空态和 1280 宽长文件名数据截图。CAD 的长文件名记录仅通过浏览器响应拦截临时提供，没有写入后端。

1280px 及以上测试窗口中，所有列与操作完整显示，操作按钮距离表格右边缘约 8px。1152px 下模型与点云表格、1024px 下三个表格需要内部横向滚动；保留可读列宽，不将按钮挤压或覆盖字段。

`npm run build` 通过，仅有既存的大块体积提示；`git diff --check` 通过。
